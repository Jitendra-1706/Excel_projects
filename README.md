# 🍕 Pizza Sales Data Analysis Project

This project analyzes pizza sales data to uncover trends in revenue, product performance, customer behavior, and operational efficiency. The goal is to generate insights that help optimize menu strategy, improve sales, and identify peak demand patterns.

---

## 📂 Project Files

- **pizza_sales Project.xlsx** — The main dataset used for analysis and to create Dashboards in excel 
- **pizza sales.SQL** — For Deep analysis

---

## 🎯 Project Objectives

- Understand total revenue performance  
- Identify top-selling and low-selling pizzas  
- Analyze order trends by time, date, and pizza size  
- Track customer purchasing behavior  
- Identify operational patterns such as peak hours and best-performing categories  

---

## 🛠 Tools Used

- **Excel** — Data cleaning, pivot tables, charts  
- **SQL** — Data querying and deeper analysis  

---

## 🔍 Key Metrics Analyzed

- **Total Revenue**  
- **Total Orders**  
- **Average Order Value (AOV)**  
- **Pizza-wise Revenue Contribution**  
- **Category-wise Performance**  
- **Daily / Monthly / Hourly Sales Trends**  
- **Top 5 & Bottom 5 Pizzas**  

---

## 📊 Analysis Insights (General Examples)
